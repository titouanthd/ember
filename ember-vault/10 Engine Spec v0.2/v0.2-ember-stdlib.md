# `ember-stdlib`: v0.2 delta

v0.1 has no spec file for `ember-stdlib` (see [[ember-stdlib]]); this note
records what v0.2 adds. Index: [[v0.2 Spec Index]].

## 1. Text helpers

Round V1.4 (no ADR: a library module, no engine contract changes).
Replaces the `centered` / `shadowed` / `draw_text_bold` copies that
bullet-hell, asteroids, freecell, memory, minesweeper, pagoda, taiji,
zhuo-ji and ember-wars kept after the macroquad `fonts` / `graphics`
modules were deleted (M5.1).

```rust
// ember_stdlib::text
pub const BOLD_OFFSET: f32 = 0.6;
pub enum Align { Left, Center, Right }          // Default: Left
pub struct Shadow { pub offset: Vec2, pub color: Color }
pub struct TextStyle {
    pub size: f32, pub color: Color,
    pub font: Option<FontId>,                     // None: the default font
    pub align: Align,
    pub shadow: Option<Shadow>,
    pub bold: f32,                                // 0.0: off
}
impl TextStyle {
    pub fn new(size: f32, color: Color) -> Self;
    // builders: align, centered, right, font, color, shadow(offset, color), bold, bold_by(px)
}

pub fn draw(r: &mut dyn RenderingServer, text: &str, pos: Vec2, style: &TextStyle);
pub fn measure(r: &dyn RenderingServer, text: &str, style: &TextStyle) -> TextMetrics;
pub fn left_edge(r: &dyn RenderingServer, text: &str, x: f32, style: &TextStyle) -> f32;

// The common call shapes, default font:
pub fn centered(r, text, cx, y, size, color);
pub fn right(r, text, rx, y, size, color);
pub fn centered_shadowed(r, text, cx, y, size, color, offset);   // black shadow
```

**Rules**

- `pos` is an anchor x and a **baseline** y, as `draw_text` takes them;
  `Align` says whether x is the left edge, centre or right edge.
- Alignment uses `measure`: the font's width at `size`, plus `bold` for
  a bold style (the shadow is not counted). A non-bold style gives the
  same pixels as the games' own helpers.
- `draw` paints the shadow first, at the aligned position plus its
  offset, then the text. Bold paints each of those twice, the second
  pass `bold` px to the right (the shadow is bold too).
- A `font` goes through `draw_text_with_font` / `measure_text_with_font`.
- Empty text draws nothing and measures `0` wide.

No game is migrated in V1.4; each drops its local copy when a round
touches it.
