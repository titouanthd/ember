# 21 — `ember-scene`: v0.2 delta

Changes against [[21-ember-scene]]. Index: [[v0.2 Spec Index]].

## 1. Frame snapshot on NodeContext and DrawContext

Round V1.1, [[v0.2-50-design-decisions#ADR-050: Frame snapshot on `NodeContext`|ADR-050]].

```rust
impl NodeTree {
    pub fn frame(&self) -> u64;   // completed `process` passes (v0.1)
    pub fn time(&self) -> f64;    // new: sum of every `process` dt
}

impl<'a> NodeContext<'a> {
    // === Frame snapshot ===
    pub fn time(&self) -> f64;            // NodeTree::time
    pub fn frame(&self) -> u64;           // NodeTree::frame
    pub fn viewport(&self) -> Rect;       // RenderingServer::viewport
    pub fn camera(&self) -> Camera2d;     // RenderingServer::camera
    pub fn pointer(&self) -> Vec2;        // first touch, else the mouse
    pub fn pointer_world(&self) -> Vec2;  // camera().screen_to_world(pointer())
}

impl<'a> DrawContext<'a> {
    pub fn time(&self) -> f64;            // set by NodeTree::draw; 0.0 outside a tree
}
```

**Rules**

- `time` advances at the **start** of `NodeTree::process`, by `dt`
  (a negative or NaN `dt` adds nothing). So one frame's `process`,
  `physics_process` and `draw` all read the same value, this frame's
  `dt` included. `physics_process` never moves it. `0.0` before the first
  `process`.
- `frame` counts completed `process` passes: `0` during the first one.
- `viewport` is the renderer's: the canvas with a virtual resolution
  ([[50-design-decisions#ADR-041: Virtual resolution with letterbox|ADR-041]]),
  otherwise the rect of the last `begin_frame`. While `process` runs that
  is the last frame drawn.
- `pointer` is in viewport coordinates (already canvas coordinates under a
  virtual resolution). The first touch point wins over the mouse, so one
  code path serves desktop and mobile.
- `pointer_world` maps it through the renderer's **current** camera
  ([[50-design-decisions#ADR-040: Camera transform (offset + zoom)|ADR-040]]).
  A game with a world camera sets it in `process`
  (`ctx.render().set_camera`) before it reads the pointer.

Replaces the per-game `frame.rs` modules (accretion, ember-wars) and the
`time` counters kept by asteroids, pagoda, zhuo-ji and others; moving those
games onto it is optional and happens when a round touches them.

## 2. Typed tree queries and node groups

Round V1.2, [[v0.2-50-design-decisions#ADR-051: Typed tree queries and node groups|ADR-051]].
Replaces the "Not yet implemented: `find_by_class`, `find_all_by_class`"
line of [[21-ember-scene]] §5.2.

```rust
impl NodeTree {
    // === Typed access and queries ===
    pub fn get_as<T: Node>(&self, id: NodeId) -> Option<&T>;
    pub fn get_as_mut<T: Node>(&mut self, id: NodeId) -> Option<&mut T>;
    pub fn find_by_class<T: Node>(&self, from: NodeId) -> Option<NodeId>;
    pub fn find_all_by_class<T: Node>(&self, from: NodeId) -> Vec<NodeId>;
    pub fn children_of<T: Node>(&self, id: NodeId)
        -> impl Iterator<Item = (NodeId, &T)> + '_;

    // === Groups ===
    pub fn add_to_group(&mut self, id: NodeId, group: &str) -> bool;
    pub fn remove_from_group(&mut self, id: NodeId, group: &str) -> bool;
    pub fn is_in_group(&self, id: NodeId, group: &str) -> bool;
    pub fn nodes_in_group(&self, group: &str) -> Vec<NodeId>;
    pub fn groups_of(&self, id: NodeId) -> &[String];
    pub fn group_names(&self) -> impl Iterator<Item = &str> + '_;
}

impl<'a> NodeContext<'a> {
    pub fn find_by_class<T: Node>(&self) -> Option<NodeId>;   // whole tree, root included
    pub fn find_all_by_class<T: Node>(&self) -> Vec<NodeId>;
    pub fn children_of<T: Node>(&self) -> impl Iterator<Item = (NodeId, &T)> + '_;
    pub fn add_to_group(&mut self, group: &str) -> bool;      // current node
    pub fn remove_from_group(&mut self, group: &str) -> bool;
    pub fn is_in_group(&self, group: &str) -> bool;
    pub fn nodes_in_group(&self, group: &str) -> Vec<NodeId>;
}

pub struct NodeRecord { /* v0.1 fields */ pub groups: Vec<String> }
```

**Rules**

- A *class* is the Rust type: a node matches `T` when it downcasts to
  `T`. A node checked out for its own callback matches nothing (as
  `get` returns `None` for it).
- `find_by_class` / `find_all_by_class` on the tree search the
  descendants of `from`, excluding `from`, in `descendants` order
  (depth-first, top-down, child order — the `process` order). The
  `NodeContext` forms search from the root and include it.
- `children_of` is direct children only, in child order.
- Group membership lists nodes in **join order**; leaving and rejoining
  moves a node to the back. `groups_of` is in join order too;
  `group_names` is sorted. `add_to_group` returns `false` for a repeat,
  an empty name or a stale id; `remove_from_group` `false` if not a member.
- Any live node can be grouped, attached or floating. A node queued by
  `spawn` may join at once and is listed once flushed in.
- Removing a node (`remove`, a flushed `despawn`, `clear`) takes it out
  of every group; a group with no members left is gone from
  `group_names`.
- Groups are saved in `.escene` ([[v0.2-30-escene-format]]).

**§14 Q6 (new), groups:** *Should nodes have groups?* Yes, from v0.2
(ADR-051; decided 2026-11-28). `@Group` in `find` paths (§5.6) is still
not supported.

## 3. `TileSet` and the `TileMap` node

Round V2.1, [[v0.2-50-design-decisions#ADR-053: `TileSet` and the `TileMap` node|ADR-053]].
New module `ember_scene::tiles`; the first built-in scene node.

```rust
pub const EMPTY: char = ' ';

pub struct Tile {
    pub symbol: char,                 // the tile's id
    pub name: String,
    pub atlas: Option<(u32, u32)>,    // atlas cell; None: a colour rect
    pub color: Color,                 // tint, or the rect's fill
}
impl Tile { pub fn solid(symbol, name, color) -> Self; pub fn atlas(symbol, name, col, row) -> Self; }

pub struct TileSet {
    pub texture: String,              // asset path, may be empty
    pub tile_size: Vec2, pub spacing: f32, pub margin: f32,
    pub tiles: Vec<Tile>,
    pub texture_id: Option<TextureId>,   // runtime, never saved
}
impl TileSet {
    pub fn from_ron(text: &str) -> Result<Self, SceneError>;
    pub fn to_ron(&self) -> String;
    pub fn validate(&self) -> Result<(), SceneError>;
    pub fn tile(&self, symbol: char) -> Option<&Tile>;
    pub fn region(&self, col: u32, row: u32) -> Rect;   // atlas pixels
    pub fn load_texture(&mut self, assets: &AssetServer, r: &mut dyn RenderingServer) -> Result<(), AssetError>;
    // builders: new, with_atlas, with_tile, with_texture_id
}
impl Asset for TileSet { /* ".etileset" */ }

pub struct TileMap { pub position: Vec2, pub cell_size: Vec2, pub z: f32,
                     pub visible: bool, pub tile_set_path: String, /* cells */ }
impl TileMap {
    pub fn new(width: usize, height: usize, cell_size: Vec2) -> Self;
    pub fn from_rows(rows: &[&str], cell_size: Vec2) -> Self;
    pub fn width(&self) -> usize;  pub fn height(&self) -> usize;
    pub fn cell(&self, col: usize, row: usize) -> Option<char>;
    pub fn set_cell(&mut self, col: usize, row: usize, symbol: Option<char>) -> bool;
    pub fn fill(&mut self, symbol: Option<char>);
    pub fn resize(&mut self, width: usize, height: usize);
    pub fn used_cells(&self) -> impl Iterator<Item = (usize, usize, char)> + '_;
    pub fn rows(&self) -> Vec<String>;
    pub fn set_rows<S: AsRef<str>>(&mut self, rows: &[S]);
    pub fn set_tile_set(&mut self, set: Arc<TileSet>);
    pub fn tile_set(&self) -> Option<&TileSet>;
    pub fn tile_at(&self, col: usize, row: usize) -> Option<&Tile>;
    pub fn cell_to_world(&self, col: usize, row: usize) -> Vec2;    // top-left
    pub fn cell_center(&self, col: usize, row: usize) -> Vec2;
    pub fn cell_rect(&self, col: usize, row: usize) -> Rect;
    pub fn world_to_cell(&self, world: Vec2) -> Option<(usize, usize)>;
    pub fn bounds(&self) -> Rect;
    // builders: named, at, with_tile_set

```

**`.etileset` file**

```ron
(
    texture: "tiles/courtyard.png",   // optional
    tile_size: (16.0, 16.0),
    spacing: 0.0, margin: 0.0,        // optional
    tiles: [
        (symbol: '#', name: "wall",  atlas: Some((0, 0))),
        (symbol: '.', name: "floor", atlas: Some((1, 0))),
        (symbol: 'x', name: "hole",  color: (0.0, 0.0, 0.0, 1.0)),   // no atlas: a rect
    ],
)
```

**Rules**

- Symbols are printable, not `' '`, and unique within a set; a control
  character never enters a map (`set_cell` refuses it, `set_rows`
  reads it as empty).
- `set_rows`: the map is as wide as the longest row and as tall as the
  list; short rows are padded with empty cells. `rows()` returns every
  row `width` characters long. A map with no columns has no rows.
- Cell `(0, 0)` is the top-left, at `position`; `cell_size` is in world
  units. `world_to_cell` floors, so a point on an edge belongs to the
  cell right / below; outside the map, or with a non-positive
  `cell_size`, it is `None`.
- `draw` goes row by row: `draw_sprite(texture_id, cell_rect,
  region(atlas), color)` for a tile with an atlas cell when the set has a
  texture, else `draw_rect(cell_rect, color)`. Empty cells, symbols the
  set lacks, and a map with no set draw nothing.
- The game resolves the set after instantiating a scene:
  `assets.load::<TileSet>(&map.tile_set_path)`, `load_texture`, then
  `set_tile_set(Arc::new(set))`.
