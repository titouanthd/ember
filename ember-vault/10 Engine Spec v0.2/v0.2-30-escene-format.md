# 30 — `.escene` format: v0.2 delta

Changes against [[30-escene-format]]. Index: [[v0.2 Spec Index]].

## 1. Node groups

Round V1.2, [[v0.2-50-design-decisions#ADR-051: Typed tree queries and node groups|ADR-051]].
Answers [[30-escene-format]] §12 Q1 (*groups*): yes, from v0.2.

A node entry takes an optional `groups` list:

```ron
(name: "L1", class: "Lantern", parent: ".", groups: ["lanterns", "solid"]),
(name: "Box", instance: "pieces/box.escene", parent: ".", groups: ["pushable"]),
```

**Rules**

- Optional; absent (or empty) means no groups, and writers leave the key
  out. Every v0.1 file is a valid v0.2 file and saves back unchanged.
  `format` stays `1`.
- Each name is non-empty and appears once per entry; otherwise the file
  fails to parse (`SceneError::Parse`).
- At instantiation the node joins the groups in list order. On an
  `instance:` entry they are joined after the nested scene root's own
  groups (a repeat is ignored).
- `PackedScene::from_tree` / `resave` write each node's current groups in
  the order it joined them, so an unchanged load → resave keeps the text.

## 2. `TileMap` entries

Round V2.1, [[v0.2-50-design-decisions#ADR-053: `TileSet` and the `TileMap` node|ADR-053]].
No format change: a `TileMap` node is an ordinary entry whose cells are
the `rows` property, one string per row, one character per cell
(`' '` empty), in the level's own legend:

```ron
(name: "Board", class: "TileMap", z: -1.0, properties: {
    "cell_size": Vec2(48.0, 48.0),
    "position": Vec2(16.0, 32.0),
    "rows": Array([String("#####"), String("#.L.#"), String("#####")]),
    "tile_set": String("tiles/courtyard.etileset"),
}),
```

The tile set is a separate `.etileset` file named by path
([[v0.2-21-ember-scene#3. `TileSet` and the `TileMap` node|spec 21 delta §3]]).
