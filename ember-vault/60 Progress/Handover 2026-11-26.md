## Gotchas

- `make editor` edits a **scratch copy** (`target/editor/player.escene`). Never save over `assets/test_fixtures/player.escene` — the scene and editor tests read it. Restore with `git restore --staged --worktree assets/test_fixtures/player.escene`.
- Agent sessions without delete permission leave `.git/*.lock` files after commits; remove them only when no git command is running.
- Commit format is enforced by `.githooks/commit-msg` — see [[Commit & Push]].
