## Gotchas

- **Colours.** macroquad's named `RED` / `GREEN` / `YELLOW` / `GRAY` are not pure RGB, and `ember_core::Color::RED` etc. are. Copy the macroquad values when migrating (`8a1d7d9`).
- **Test changes.** Existing tests may only change mechanically: imports, `KeyCode` → `Key`, `..Input::default()`. Say so in the commit message.
- **Text.** `draw_text_ex`'s `font_scale` becomes a size multiplier.
- **Clipping.** `get_internal_gl().quad_gl.scissor` is `push_clip_rect`.
- **Editor scratch copy.** `make editor` edits a scratch copy (`target/editor/player.escene`). Never save over `assets/test_fixtures/player.escene`.
- **Git lock files.** Agent sessions without delete permission leave `.git/*.lock` files after commits. Remove them only when no git command is running.
- **Commit format.** Enforced by `.githooks/commit-msg` — see [[Commit & Push]].
