# pagoda

A one-button precision stacker: drop sliding lacquered tiles onto a pagoda,
slice the overhang, chase perfect landings, and climb as high as you can.

**Status:** complete (Milestone 5). 112 tests, clippy-clean, native + WASM,
mobile-friendly web shell, procedural SFX. Music is the only missing feature.

**▶ Play in your browser:** the committed bundle is in `dist/web/`. Serve it
locally with `python3 -m http.server` (see below).

## Running

### Native

```sh
cargo run --release -p pagoda
```

The native best score is stored in `best_score.ron` next to the executable
(or in the working directory). Delete it to reset the record.

### Web (WASM)

```sh
./tools/build-web.sh
cd dist/web && python3 -m http.server 8080
# → http://localhost:8080
```

The web best score is in-memory only: it survives menu/game transitions but
not a page reload. A `localStorage` bridge is future work (see
`games/accretion/tools/localStorage_plugin.js` for the proven pattern).

## Controls

| Input | Action |
|---|---|
| `Space` / `Enter` / click / tap | Drop the block; start; restart |
| Click/tap the speaker icon | Mute / unmute (the only mute control) |

There is no keyboard mute shortcut. The speaker hit area is 96 virtual px so
it is usable on a phone, and taps on it never start or drop a block.

## Rules

- The tile slides horizontally and speeds up as the tower grows.
- The overhang is sliced off; the next tile is the intersection width.
- A miss (zero intersection) ends the run.
- A **perfect** landing (within a speed-scaled window, min 4 px) keeps the
  full width, adds 2 px up to the base width, and starts/extends a combo.
- The camera pans up; the palette advances through Chinese pigments
  (celadon → turquoise → indigo → cinnabar → gold).
- Perfects play an ascending pentatonic chime; the combo selects the note.

## Audio

All SFX are procedural, generated by `tools/generate-sounds.py`, and committed
as 44.1 kHz mono 16-bit WAVs. `quad-snd` resamples anything else, so a test
asserts the format. Missing clips degrade to silence.

## Fonts

DejaVu Sans Mono is the default UI font. A 9 KB Noto Sans SC subset supplies
`宝塔`, `完美`, `终`, and `新纪录`; if it fails to load, the English labels take
over and gameplay is unaffected. Regenerate it with `tools/subset-font.sh`.

## Tests

```sh
cargo test -p pagoda
```

112 tests. The suite covers slicing, the speed-scaled perfect window, combos,
camera math, letterbox mapping, WAV headers, and persistence. Clippy and fmt
are clean.
